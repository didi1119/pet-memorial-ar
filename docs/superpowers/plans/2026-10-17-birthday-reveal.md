# 黑醬生日揭曉與QR Implementation Plan

**Goal:** 揭曉前整站需使用者指定密碼；現場成功揭曉一次後永久恢復公開，QR讓現場觀眾直接用手機看。
**Architecture:** 現有Cloudflare Pages advanced-mode Worker攔截全部路徑，獨立D1只存揭曉狀態與匿名嘗試次數。密碼摘要僅伺服器端；預覽與正式狀態分開。沿用既有剪紙生日頁，AR旁增加本機生成的標準QR小卡與可放大投影的對話框。
**Tech Stack:** Pages Worker、D1免費額度、原生HTML/CSS/JS、Python QR編碼、Node測試、Playwright。

- [x] 寫鎖定、資產拒絕、錯誤密碼、同來源驗證、頻率限制、成功後跨訪客公開、故障封閉的測試，先看失敗。
- [x] 實作中性等待頁及一次揭曉Worker；用本機D1驗證，不對正式站輸入成功密碼。
- [x] 生成指向正式網址的標準QR；AR旁紙卡、投影放大對話框、鍵盤關閉、QR圖像可下載。
- [x] 同步來源與雜湊部署檔；保留原模型、影片及互動，避免依賴舊機器字型建置路徑。
- [x] 手機390px／投影1440px實測、QR解碼、6個GLB/USDZ SHA驗證、部署到既有heijiang-always-here。
- [x] 正式站只驗等待頁、錯碼及素材403；成功使用者指定密碼只在本機驗，正式保持未揭曉。保存操作與移除保護說明。

已採用使用者確認的臨時揭曉方案，使用者指定密碼只由主人現場輸入。成功即全站公開，此後觀眾不必再輸密碼。舊下載與已知舊部署快照不可能由新版收回；僅保護本次正式部署。QR使用深棕實心方格、完整四模組留白，不在碼內放圖案。
